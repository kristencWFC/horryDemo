4. Payments and PCI

Anything a caller says or keys in reaches the AI as text, so Savannah never takes a card number. She uses the card on file or texts a secure link, and only a token and the result come back. Horry's contact center never handles card data, so their SAQ D scope doesn't change. For keypad payments in production, a PCI-certified payment service collects the digits and returns only the result.

[CONFIRM] The WxCC recording must pause during any keypad payment.
