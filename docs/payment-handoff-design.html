Payment Hand-off Design

The live agent hands Dorothy to Savannah for the payment and never hears it. The WFC AI Controller sits in the middle of every agent-first call, the same way it did for Live Translate: it owns Dorothy's leg and the agent's leg separately, so it can hold one and send the other to Savannah, then put them back together. The agent's Desktop task never ends.

Internal build plan, not for the client. Step through section 1, then approve or change the pieces in section 2. Nothing is built until you say go.

3. What doesn't change

  • Savannah on (storm): the flow bridges to 1122 with horryelectric as today; the ivr-controller handles it; escalation returns by BYE headers. Untouched.
  • Payment reminders (use case 3), web chat, email, Customer Review: untouched. The dashboard already shows the path "Agent → Savannah (payment) → agent".
  • Member tab lookup: by caller number. Live Translate proved the re-entry leg presents the original number, so Dorothy pops exactly as she did tonight.
  • Demo caller setting: same one place (AI Operations → Demo caller).
