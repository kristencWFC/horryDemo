Payment Hand-off Design

The live agent hands Dorothy to Savannah for the payment and never hears it. The WFC AI Controller sits in the middle of every agent-first call (the same shape Live Translate uses): it owns Dorothy's leg and the agent's leg separately, so it can hold one and send the other to Savannah, then put them back together. The agent's Desktop task never ends. Members dial 972-903-8486 for this; the controller brings them back in on 972-430-9658, Horry's own numbers end to end.

Internal build plan, not for the client. Approved by Kristen 2026-11-03 with two changes: Dorothy hears WxCC's own queue treatment, not a parked ringback (step 2), and the re-entry uses Horry's own demo line through new CUBE dial-peers 1145/1146, so nothing is shared with the other demos. Section 5 lists every hop by number; section 6 is the set-up order.

3. What doesn't change

  • Savannah on (storm): the flow bridges to 1122 with horryelectric as today; the ivr-controller handles it; escalation returns by BYE headers. Untouched.
  • Payment reminders (use case 3), web chat, email, Customer Review: untouched. The dashboard already shows the path "Agent → Savannah (payment) → agent".
  • Member tab lookup: by caller number. Live Translate proved a CUBE re-entry leg presents the original number; dial-peers 1145/1146 are copies of that pair, so Dorothy pops exactly as she did tonight. [CONFIRM] on the first call.
  • Demo caller setting: same one place (AI Operations → Demo caller).
  • The demo line 972-430-9658 and the main flow: unchanged for the storm and normal-day stories.
  • Agent Live Assist and Live Translate: their re-entry (+12078886051, KC_Assist_2, Q_KC_Telephony, dial-peers 1141/1142) is not touched.

6. Set-up order for Kristen

The step-by-step walk-through happens live in chat once the build is done; this is the order it will follow.

  1. Deploy the service: cd /opt/horryDemo && git pull --ff-only && npm ci && npm run build && sudo systemctl restart horry-demo.
  2. Install deploy/freeswitch/dialplan-horry-agent-first.xml into /etc/freeswitch/dialplan/public/ivr_menu.xml above ivr_handler, then fs_cli -x reloadxml.
  3. Add FS_ESL_ENABLED=true and FS_ESL_PASSWORD=… to /opt/horryDemo/.env; restart horry-demo.
  4. Check https://kcdev2.workflowconcepts.com/horry/health shows agentFirst: { esl: connected }.
  5. CUBE: dial-peers 1145 (incoming called-number +19724309658) and 1146 (destination-pattern +19724309658 → Webex) — done 2026-11-03.
  6. Designer: KC_Horry_Electric, 9729038486 DNIS branch → Bridge Transfer 1122 with the two headers; success → Disconnect; failure → Queue Q_Horry_Billing. The main Savannah-off branch stays as is (optional guard: REST agent-first/by-ani + Case before the Global_StormMode Case).
  7. Publish the flow.
  8. Test A: Savannah off, call (972) 903-8486 as David; the agent rings with David on the Member tab; talk; hang up.
  9. Test B: as Dorothy; click Hand payment to Savannah; agent hears the announcement and hold music; Dorothy pays by e-check on file; the Member tab shows the steps; Savannah hangs up and the agent is back with Dorothy.
  10. Test C: start a hand-off and press Cancel hand-off (re-bridge); then a hand-off with Savannah unreachable (expect the failed step and re-bridge within 20 s).
